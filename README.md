# Scholarship Finder 

Scholarships-only V1. The Save flow and local dashboard are stable for testing.

Includes search/filtering, country eligibility labels, Save -> account/guest prompt, guest persistence, Dashboard, private notes, application stages, deadline countdown when a real date is present, closing-soon sorting, and official-source links.

The current catalog intentionally avoids invented dates. Exact deadline values should be added only after official verification. True cross-device accounts require the secure backend connection.
